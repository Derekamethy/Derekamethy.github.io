01 / Flagship research · Tyndall

CRFID domain generalisation

Can a chipless RFID classifier recognise the same tag under an unseen reader geometry?

Using existing measurements from Tyndall, I built the ML pipeline, grouped evaluation and diagnostics to test transfer to an unseen combination of reader distance and angle.

Characterised the limits of transferNear-chance accuracy on the held-out geometry · 12,600 spectra · 252 physical-condition blocks

Skills demonstrated: experimental design, model comparison and failure analysis under changing sensor conditions.

Evaluation of existing data from one acquisition campaign.

Methods, findings & scope

Evaluation design

Repeated sweeps stay within the same physical-condition group. Three reader positions supply development data; a fourth holds out the combined 150 mm / 45° geometry. Familiar-condition recognition and unseen-geometry transfer are evaluated separately.

Findings

The C1 configuration achieved 15.66% accuracy across five seeds, against a 14.29% uniform-chance reference for seven classes. Tested source-only interventions did not establish reliable improvement over matched controls. Signal and representation diagnostics investigated these limitations; they do not establish that all tag information was lost.

My contribution covers preprocessing, modelling, evaluation and diagnostics on existing measurements. The figure’s GHz axis is nominal because exact sample-by-sample frequency coordinates are unavailable. Full comparisons and supporting studies are documented in the case study.

03 / Digital signal processing

EEG multirate DSP

Reduce the sampling rate while protecting the useful EEG analysis band.

I designed an 8/125 rational conversion and Kaiser FIR, implemented a direct reference, and integrated SciPy’s polyphase resampler using the same coefficients.

500 → 32 Hz93.6% fewer samples · protected band: 0.5–12.5 Hz

Skills demonstrated: filter design, numerical equivalence and spectral validation.

Validated on one 60 s recording; clinical performance was not evaluated.

Filter design, validation & scope

Design

L = 8, M = 125; a 4,145-tap Kaiser FIR at the 4 kHz intermediate rate. The 60 dB stopband target measured 59.89 dB on the validation grid. Eight-second windows give 0.125 Hz bin spacing; Hann-window spectral resolution is broader.

04 / Engineering prototype

Eight-channel EEG simulator

Make the signal source, device interface and verification path testable before hardware integration.

I built a Python desktop application and browser control console for synthetic or recorded EEG, channel controls, timed playback, fault injection and virtual 16-bit DAC mapping.

8 channels · 3 verification levelsDesktop + browser software · deterministic mock measurements

Skills demonstrated: software architecture, device interfaces and automated verification.

Software proof of concept with mock measurements; physical MCU/DAC integration remains future work.

Signal chain & implementation boundary

Implemented software

Synthetic/NPZ and optional EDF input, monotonic-clock playback, channel selection and digital amplitude scaling. The browser console reuses the maintained signal, playback, fault-condition, virtual-DAC, mock-device and validation logic rather than serving as a static mock-up. Virtual 16-bit codes represent a configurable ±200 µV target range.

  1. EEG → desktop / browser control → virtual DAC / mock deviceImplemented and exercised in software
  2. USB / serial adapter → MCU buffer, timer & DMASerial skeleton exists; waveform transfer and firmware remain to implement
  3. Multi-channel DAC → analogue scaling → µV output → EEG acquisitionProposed physical path; no measured hardware output

Verification

Separate simulator-output, acquisition and event-timing checks compare deterministic software references. The maintained suite contains 41 tests covering waveform handling, DAC mapping, protocol behaviour, fault conditions, browser-controller logic, visualization and validation, with CI checks. These checks do not measure a physical acquisition device.
